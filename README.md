# AI Resume Analyzer

A Python project that compares a resume with a job description and gives a match score, skill gaps, and AI feedback using Google Gemini.

## Features
- Reads resume and job description from text files
- Finds matching and missing skills
- Calculates a match score
- Gives improvement suggestions
- Gives AI feedback using Gemini API

## Tech Used
- Python
- Google Gemini API (google-genai)

## How to Run
1. Install the library: `pip install google-genai`
2. Set your Gemini API key as an environment variable named `GEMINI_API_KEY`
3. Create `resume.txt` and `job.txt` in the same folder
4. Run: `python main.py`
